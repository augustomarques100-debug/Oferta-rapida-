# Oferta Rápida — V1.2

Projeto Expo/React Native preparado para gerar APK Android via Expo EAS Build.

## Build automático pelo GitHub Actions

1. Configure um secret do repositório chamado `EXPO_TOKEN` com um token de acesso da sua conta Expo.
2. Abra a aba **Actions** no GitHub.
3. Selecione **Build Oferta Rapida APK**.
4. Toque em **Run workflow**.
5. O GitHub executará o build na nuvem usando o Expo EAS.

O perfil `preview` está configurado para gerar APK instalável diretamente no Android.
